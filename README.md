# GLORIA · 荣光，永恒罗马

依据《Gloria · Roma Aeterna》GDD v2.9 开发的浏览器可玩原型。手机竖屏及桌面浏览器均可使用。

## 本地启动

需要 Python 3。无需安装前端依赖。

```sh
npm start
```

打开 http://localhost:4173。不要直接以 file:// 打开 index.html，浏览器会限制 ES 模块加载。

```sh
npm test
```

19 项 Node 内置测试覆盖经济、路网、供水、成长、贸易、民怨、敕令、战斗和存档验证。

## 先玩什么

选择罗马花园，放在初始广场北侧的空地 (7,6)；在其东侧 (8,6) 建祭坛，即可覆盖五栋住宅，使总幸福达到 32。坐标从 0 起计，界面通过等距格子操作。按 Esc 取消建造后，可拖动、放大地图。

在主街西侧建麦田和粮仓，随后扩建住宅。水井最多供应六栋住宅；第七栋起需要新水源。基建、产业、防务与贸易让城市继续成长。所有功能建筑都必须邻接已连通广场的四向道路。孤立道路不生效。

数字键 1 道路，2 棚屋；空格暂停；Esc 取消。手机点底部「营造」打开建筑栏。贸易驿站可点击建筑进入交易，也可从设置进入。

## 已实现

- 16×16 等距可建造地图，程序化建筑和地形，选择、平移、缩放、连续铺路、幽灵放置。
- GDD 开局 580 金、120 粮、90 石、40 铁、50 军粮，60 人、五住宅、井与广场。
- 四向广场路网、限额供水；建筑级税收、粮耗、劳动力，工业缺工比例减产；储粮、地力衰减与休耕。
- 两层幸福、粮食四态、民怨三阶、四档税率、三池分账、拨款与赈济。
- 8 个一次性微目标；简化连续敕令，后续轮次增加目标建筑数量；行省地位升级；贸易与冷却。
- 条件驱动首次入侵、后续间隔入侵、移动敌人、射程塔防、兵营加成及劫掠。
- 忠诚献金、简化庆典筹备、凯旋门门槛与主线终点提示。
- 6 名试玩居民、纪事与远方短讯、首祭坛铭文、首喷泉罗马时刻、漫步与 PNG 明信片。
- 本地自动存档、JSON 备份导入导出、无离线资源结算，后台及弹窗期间模拟暂停。

## 原型与完整 GDD 的边界

此交付用于验证建造经营循环，尚非完整 iOS 成品。正式美术与环境音、全量市民与生命周期、Felix 送信、灾害、一次性冬天、路线政令、多解敕令、贸易合同、帝国阶段建筑、离任演出、十四天回访等仍待实现。当前战斗移动、劫掠、庆典筹备、君主忠诚事件采用简化实现；住宅即时完成建造。

## 规则取舍

- 第 6.1 节人口增长与第 9.3 节冲突，采用 9.3 的每 15 秒 +6/+9，与开局推演一致。
- 第 17 章与第 6.4 节安全期冲突：民怨采用人口 <120 且未建粮仓的规则。
- 供水、幸福和攻击范围采用曼哈顿格距；道路严格四向。
- 开局地块位置为试玩布局设计，预置建筑与资源数量遵守 GDD。
- 情感日志、漫步、市民致谢不授予资源或声望。
- 视觉为可替换的 Canvas 程序化原型资产；正式 iOS 美术应按第 26 章继续制作。

## 文件

- data.js：建筑、任务、居民与文案配置。
- engine.js：与 UI 无关的模拟及有效性验证。
- map.js：等距渲染、坐标反算与地图手势。
- app.js：界面、存档、交互与流程。
- style.css、index.html：响应布局。
- engine.test.js：核心规则测试。
